# Site do RCP Flow

Página de apresentação, política de privacidade e termos de uso (HTML estático, sem rastreamento).
Publicado no GitHub Pages; o domínio próprio entra no arquivo `CNAME`.

Antes de publicar, troque os marcadores em todos os `.html`:
- `__RESPONSAVEL__`: razão social (ou nome) do responsável, como no CNPJ
- E-mail de contato já preenchido: contato@rcpflow.com.br
- Domínio: rcpflow.com.br (arquivo `CNAME`)

As capturas em `img/` são do próprio app (tema claro e escuro). O guia em PDF é gerado por
`docs/tutorial-instalacao/gerar_pdf.py`.
